# AGENTS — fourier-transform-research

## Overview
MuJoCo-only spectral joint flow (MFPO) + skrl PPO/SAC baselines → halfcheetah/walker/hopper. Small-param (<20M) pipeline: proprio context → Hann-rFFT K=5 tokens [B,5,64] → joint DCT [A*,S*] 135-dim → joint flow transformer (1.0*MSE_A+0.5*MSE_S) → Euler 0→1 steps 16/8 → IDCT + gripper {0,1}. CPU-first default on gfx1103 APU (780M, 16GB shared RAM) — ROCm gfx1101 wheels stub-only, fallback to CPU torch via `requirements-local.txt` `--extra-index-url https://download.pytorch.org/whl/cpu`. SIGReg = VICReg var+cov, single home (`sigreg_losses`, λ=0.1) — no Barlow/EMA. MJX gated behind `MFPO_USE_MJX=1` (stub `is_stub=True` default, `src/mfpo/mjx_adapter.py`). Train via `scripts/train.py`; notebooks generated by `scripts/build_notebook.py` (gitignored, regenerable).

## Conventions
- Tensor order: `B` batch chunks, `N` context 16, `H` chunk 8, `K` 5, `D` 128, `Dk` 64, `Da` env-dependent, `Ds` 128, `135=Da+Ds`
- fp32 only — never autocast/half/bfloat16 (guard test enforces), no torch.compile
- LEGACY_MUJOCO=True collapsed — MuJoCo flat Box only, no LIBERO dict adapter
- CPU-first training default: `requirements-local.txt` pins CPU torch (`--extra-index-url https://download.pytorch.org/whl/cpu`); follower env `CUDA_VISIBLE_DEVICES=""`/`HIP_VISIBLE_DEVICES=""` for CPU-forcing if needed; ROCm gfx1103 APU (780M) — GPU wheels unavailable, `HSA_OVERRIDE_GFX_VERSION=11.0.1`+`PYTORCH_ROCM_ARCH=gfx1101` legacy shim now replaced by CPU fallback (see `.omo/evidence/t1-arch-fix.log`)
- MJX gated contract: `MFPO_USE_MJX=1` only, `src/mfpo/mjx_adapter.py` `is_stub=True` default, `MjxObsAdapter`/`MjxWrapper` stub pad/truncate, gated `MjxModelWrapper` exact-dim assert + `require_mjx_gate()` RuntimeError + function-local jax/mujoco.mjx imports, never imported in runner/baselines
- wandb default-on contract: `MFPO_DISABLE_WANDB=1` is the ONLY off switch (anything else → enabled); `wandb_logging.py` module-level REQUIRED `import wandb` (sole importer; absent → hard ImportError); `init_wandb_run_for_method` sets project=method, name=None (auto), group={method}_{env}, global `wandb.define_metric("*", step_metric="global_step")`, returns bool; init failure is FATAL (no fallback); runners route via `init_wandb_run_for_method`+`log_eval_details`+`log_metrics(data, step=global_step)`+`finish_run()`; metrics: train/* (7 diag+total_loss), eval/* (mean/max/std/length/count+episodes Table+reward_improvement), gae/*, timing/*; wandb in main requirements, `wandb/` git-ignored
- MuJoCo flat Box obs only (no dict adapters)
- Frozen per-branch DCT stats `denormalize_joint_targets` atol 1e-6 invariance
- einx tensor notation (`einx.id`) in dct_utils/baselines/collector/fpo_core — torch↔einx 1e-6 parity locked by `tests/test_einx_migration.py` (sanctioned deps exception, plan `einx-migration`)
- Success branching: single scalar λ=0.1 VICReg SIGReg (`l_var + l_cov` on Z via `sigreg_losses`)
- Single-truth helpers (post-deslop): `total_update_loss` (fpo_core, caller-supplied cfg weights), `decode_chunk_actions` (runner, one IDCT clamp), `init_wandb_run_for_method`/`log_eval_details` (wandb_logging, shared runner/baselines); YAML↔dataclass keys locked by `tests/test_config_yaml_parity.py`
- Train entry: `scripts/train.py --method {mfpo,ppo,sac} --env <Env-v5>` (single) or `--matrix --methods/--envs/--seeds` (+`--tiny` = Hopper/seed0/3 runs); `--config` YAML overlays dataclass defaults (CLI > YAML > dataclass); exits 0/1/2/4
- Commit `refactor(scope):` one atomic per verified todo, suite green at each

## Anti-Patterns
- DO NOT vend LIBERO, full ACT/Diffusion, or add extra envs (MuJoCo-only: halfcheetah/walker/hopper)
- DO NOT add covariance/Barlow/EMA heads to the flow loss (VICReg SIGReg-only gate)
- DO NOT add pinned deps beyond torch/gymnasium/sklearn/skrl/pytest/jupytext/nbformat/matplotlib/numpy/pyyaml (+einx>=0.4 sanctioned exception, plan `einx-migration`)
- DO NOT change CSV schemas (MuJoCo 3-col) or RUN_MATRIX cardinality (45) silently
- DO NOT reintroduce `as any`/`# type: ignore` or fp16 paths (f2-quality gate scans)
- DO NOT touch `analysis.py` statistics/plotting (project, IQM n_boot 2000, CI) without explicit plan amendment — risk boundary
- DO NOT import `wandb` outside `mfpo.wandb_logging` (sole importer, module-level hard REQUIRED import); do NOT log secrets/API keys
- DO NOT leave `wallclock_h 0.0` placeholder unacknowledged

# Notebooks

The standalone notebook carries **no source code**. It clones this repo, installs
deps, and shells out to `scripts/train.py` with `!` (eval runs inside
training → `eval_history.csv`). Source of truth stays in `src/`.

| Notebook | Cells | When |
|---|---|---|
| `spectral_joint_flow.ipynb` | 8 | SJFPO single runs (smoke + full 1M). Use this on Colab. |

Never hand-edit the ipynb — it is generated by `scripts/build_notebook.py`.

## Build

```bash
python scripts/build_notebook.py                 # spectral_joint_flow.ipynb
python scripts/build_notebook.py -o custom.ipynb # same content, other path
# Structure gate (8 cells, md/md/code×6) runs inside the builder.
```

## Cells

1. Markdown title: what the notebook runs.
2. Markdown: private-repo access (PAT with Contents:read, via `GITHUB_TOKEN` or prompt).
3. Code: `getpass` token → `!git clone https://<token>@github.com/dzungphieuluuky/spectral-joint-policy.git` (skipped if present) → `%cd` into it.
4. Code: `!pip install -q -r requirements-linux.txt`.
5. Code: `!PYTHONPATH=src python scripts/train.py ...` (smoke + full run).

## Colab Tips

- Push the repo (including `requirements-linux.txt`) to GitHub first, then
  File → Open notebook → GitHub → pick the `.ipynb` (needs repo access).
- Use a fine-grained PAT scoped to this repo; prefer the `GITHUB_TOKEN`
  Colab secret over pasting into the prompt.
- GPU runtime recommended for full runs; smoke works on CPU.

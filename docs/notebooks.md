# Notebooks

The standalone notebook embeds the full source tree (one `%%writefile` cell
per runtime file: `src/`, `scripts/train.py`, `configs/`,
`requirements-linux.txt`) so Kaggle runs with internet OFF. Deps come from
the attached wheels dataset. Source of truth stays in this repo — rebuild
after changing any source file.

| Notebook | Cells | When |
|---|---|---|
| `spectral_joint_flow.ipynb` | 33 | SJFPO single runs (smoke + full 1M). Use this on Kaggle. |

Never hand-edit the ipynb — it is generated by `scripts/build_notebook.py`.

## Build

```bash
python scripts/build_notebook.py                 # spectral_joint_flow.ipynb
python scripts/build_notebook.py -o custom.ipynb # same content, other path
# Structure gate (writefile coverage + train cell) runs inside the builder.
```

## Cells

1. Markdown title: what the notebook runs.
2. Markdown: attachments (wheels dataset → `WHEELS_DIR`) and secrets.
3. Code: `!mkdir -p` the source tree.
4. Code: runtime detection + secret loading (`kaggle_secrets` on Kaggle).
5. Code × 25: `%%writefile` cells recreating every runtime file.
6. Code: offline `pip install --no-index` from the wheels dataset.
7. Code: wandb login (skipped silently without key).
8. Code: `!python scripts/train.py ...` smoke + full run.

## Colab Tips

- Push the repo (including `requirements-linux.txt`) to GitHub first, then
  File → Open notebook → GitHub → pick the `.ipynb` (needs repo access).
- Use a fine-grained PAT scoped to this repo; prefer the `GITHUB_TOKEN`
  Colab secret over pasting into the prompt.
- GPU runtime recommended for full runs; smoke works on CPU.

# Notebooks

## Which Notebook to Use

| Notebook | Cells | When |
|---|---|---|
| `spectral_joint_flow.ipynb` | 61 | **Primary deliverable — SJFPO spectral flow policy**. Self-contained, Kaggle-ready. Use this on Kaggle. |
| `flow_matching_vs_ppo_sac.ipynb` | 47 | SJFPO vs PPO/SAC comparison on MuJoCo (preserved). |

Never hand-edit either ipynb — they are generated by `scripts/build_notebook.py`. Edit `src/sjfpo/*.py` and rebuild.

## Build

```bash
python scripts/build_notebook.py                 # both
python scripts/build_notebook.py --spectral-only # only spectral_joint_flow.ipynb
python scripts/build_notebook.py --legacy-only   # only flow_matching_vs_ppo_sac.ipynb
# After either:
python -c "import nbformat; nbformat.validate(nbformat.read('spectral_joint_flow.ipynb',as_version=4)); print('validate ok')"
grep -c "from src\." spectral_joint_flow.ipynb   # expect 0 — self-contained proof
```

**Mechanism:** `src/sjfpo/*.py` are authored with jupytext percent markers + `# CELLORDER: <n>` tags. The builder concatenates modules in `CELLORDER` order, then `jupytext --to ipynb` → `nbformat.validate` → register-snippet bootstrap cells that register `sjfpo.*` modules in `sys.modules` for self-containment.

## Cell Map (spectral_joint_flow.ipynb)

1. Markdown: binding conventions, hyperparameter table, architecture table, deviation notes, limitations.
2. Setup + version asserts (`torch`, `numpy`, `sklearn`, `skrl` pins).
3. Inlined `sjfpo.*` modules (each with bootstrap + register snippet).
4. Self-test cell (raises on failure, never warns): DCT roundtrip, `RUN_MATRIX` non-empty, `sigreg_loss` finite, `aspo_surrogate`.
5. **Smoke cell** — MuJoCo tiny preset (`SJFPO_TINY_MATRIX=1`); the builder auto-prints its prune note for the legacy smoke path.
6. **Sweep cell** — iterates the matrix (tiny preset); `mkdir(parents=True)` guard tolerates empty runs dir.
7. **Analysis cell** — `analyze_results` wrapped in `try/except AnalysisError` so empty-history tiny runs don't fail; emits PNGs + summary CSV when runs exist.
9. Optional `push_checkpoints_to_dataset()` helper (wire dataset slug before use).

## Kaggle Tips

- Upload **only** `spectral_joint_flow.ipynb`. Set accelerator to T4×2 or P100 if available.
- If you modify hyperparams (`K/spectral_dim/N/H/lambdas`) do it in `src/sjfpo/config.py` locally, rebuild, re-upload — don't patch cells in the Kaggle editor.
- Checkpoints go to `/kaggle/working`; `push_checkpoints_to_dataset()` is optional — leave disabled until you wire the slug.

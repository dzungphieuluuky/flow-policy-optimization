# Notebooks

Both notebooks carry **no source code**. Each one clones this repo, installs
deps, and shells out to `scripts/train.py` with `!` (eval runs inside
training → `eval_history.csv`). Source of truth stays in `src/`.

| Notebook | Cells | When |
|---|---|---|
| `spectral_joint_flow.ipynb` | 6 | SJFPO single runs (smoke + full 1M). Use this on Colab. |
| `flow_matching_vs_ppo_sac.ipynb` | 6 | SJFPO vs PPO/SAC `--matrix` sweep + results listing. |

Never hand-edit either ipynb — they are generated by `scripts/build_notebook.py`.

## Build

```bash
python scripts/build_notebook.py                 # both
python scripts/build_notebook.py --spectral-only # only spectral_joint_flow.ipynb
python scripts/build_notebook.py --legacy-only   # only flow_matching_vs_ppo_sac.ipynb
# After either:
python -c "import nbformat; nbformat.validate(nbformat.read('spectral_joint_flow.ipynb',as_version=4)); print('validate ok')"
```

## Cells (both notebooks)

1. Markdown title: what the notebook runs.
2. Markdown: private-repo access (PAT with Contents:read, via `GITHUB_TOKEN` or prompt).
3. Code: `getpass` token → `!git clone https://<token>@github.com/dzungphieuluuky/spectral-joint-policy.git` (skipped if present) → `%cd` into it.
4. Code: `!pip install -q -r requirements-linux.txt`.
5. Code: `!PYTHONPATH=src python scripts/train.py ...` (spectral: smoke + full run; comparison: `--matrix` sweep + `find` for `eval_history.csv`).

## Colab Tips

- Push the repo (including `requirements-linux.txt`) to GitHub first, then
  File → Open notebook → GitHub → pick the `.ipynb` (needs repo access).
- Use a fine-grained PAT scoped to this repo; prefer the `GITHUB_TOKEN`
  Colab secret over pasting into the prompt.
- GPU runtime recommended for full runs; smoke works on CPU.
